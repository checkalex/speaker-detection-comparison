Assignment rule, speaker mapping and fallback counts +

The existing Checksub rule

Choose the single detected segment with the largest overlap with the subtitle. The first segment wins ties. This reproduces the editor rule; overlap from separate segments of the same speaker is not summed.

All 849 intervals match the saved Checksub exports. The scorer matched the original Ruby assignment code on all 1,694 scored model/line combinations.

One identity mapping per recording

Each anonymous model cluster is matched to at most one reviewed person, and each person to at most one cluster. The global mapping maximizes correct line count; it is never changed per line. This measures best-case grouping agreement after consistent speaker naming.

Two Dave chorus lines have five reference speakers each. They are excluded from this single-speaker score and remain included in DER and overlap evaluation.

Default assignments are visible

When no segment overlaps, Checksub defaults to speaker ID 1. Precision-3 used this fallback on 15 lines, with two correct; NVIDIA on 69 lines, with 27 correct. The main score includes this editor behavior.

Counting correct assignments only when supported by a detected segment gives 82.05% for Precision-3 and 70.84% for NVIDIA, over the same 847 lines. Incorrect-line counts are a correction proxy, not measured editing time.

01

Identical audio, isolated detection

Both models received the same 16 kHz mono WAV for each clip. This compares Precision-3 with Nemotron 3 Diarization, not the full Nemotron 3.5 Transcribe pipeline.

02

Model-assisted labels, subtitle-based times

The first four references began with Checksub’s original speaker assignments; Friends Christmas began with NVIDIA speaker labels. Those initial labels may influence human review. All five use the same Checksub transcription/alignment cue times for both models; those timings do not inherently favor either diarizer. Subtitle display boundaries can differ from audible speech. Human review does not make this a blind reference. Only Dave’s chorus has explicit overlap annotation.

03

Strict, consistent scoring

Zero boundary collar; overlap included; full-clip evaluation. Speaker IDs are matched to names globally and one-to-one, so splitting or merging identities is penalized.

04

A small, specialized sample

Three animation clips and two Friends compilations, all in English, with music, laughter and short turns. Dave and Friends Christmas exceed NVIDIA’s eight-speaker capacity. Customer recordings and other languages need separate evaluation.

05

Speed and cost need a separate test

Precision-3 used a hosted API; NVIDIA used local GPU inference. Queueing, upload and model load have different scopes. This report makes no apples-to-apples speed or cost claim.

06CONCLUSION

Precision-3 leads
on subtitle assignments.

Using Checksub’s current rule and one consistent identity mapping per recording, Precision-3 assigns 697 of 847 lines correctly (82.29%); NVIDIA assigns 627 (74.03%). That is 70 fewer incorrect line assignments. Precision-3 leads this metric in four of the five recordings.

This supports keeping Precision-3 as the provisional default for the current subtitle workflow. NVIDIA wins total DER, 41.38% versus 58.34%. Both findings are valid for this test: one measures the label on each subtitle, the other measures full speech intervals. Reference review was model-assisted, and this pilot does not measure editing time or production cost. Neither system recovers all five annotated chorus voices.

PROVISIONAL RECOMMENDATION FROM MEASURED LINE ACCURACY

BEFORE A REPLACEMENT DECISION

1

Audit the disagreements

Use the per-line CSV to find incorrect labels and default-speaker assignments. Verify the disputed speaker names by listening, and inspect whether a different assignment rule improves the same saved outputs.

2

Broaden the test set

Add customer-style interviews in our working languages. Precision-3 also leads line accuracy on the three recordings within NVIDIA’s eight-speaker limit: 76.69% versus 68.53%.

3

Measure correction work and cost

Compare actual user corrections, latency and deployment cost. Independently reviewed speech boundaries can strengthen DER evaluation; no new inference is required to rescore cached results.
